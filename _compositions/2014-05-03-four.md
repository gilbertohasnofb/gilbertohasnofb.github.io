*Four* is an algorithmic composition for string quartet which rewrites itself for every performance: its score is generated by a computer program, which rigorously follows the composer's structural ideas and rules, but also makes small decisions by itself via the use of randomly generated numbers. Thus, every little detail in this work is logical and yet unforeseen, making two scores generated by the same program look alike but never be the same. This piece is written in memory of Mário Ficarelli.
