Rosetta is an algorithmic work for solo marimba generated by a computer program. Because this program uses random procedures, a different version of this work is output at each execution. It is recommended that the performer generate a new version for each concert (more on how to generate a version below), though this is not a requirement. Also, the performer may play more than one single version on a same concert.
