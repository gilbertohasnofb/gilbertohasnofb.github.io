*O Ritual Da Sombra* is an algorithmic work for solo recorder and live electronics. Since
it is generated by a computer program that uses random numbers, a different version
of this work is output at each execution. Thus, it is recommended that the performer
generate a new version for each concert. Also, the performers may play more than one
single version on a same concert.
