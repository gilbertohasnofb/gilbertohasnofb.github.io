The generatuive sound installation 2D Virtual Acousmonium uses fiducial markers and an overhead webcam to track the position of listeners while outputting sounds via wireless headphones. Coupled with binaural processes, these techniques allow the listeners to dynamically interact with virtual sounds around them.
